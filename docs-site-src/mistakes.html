Mistakes to rules

Each mistake below happened in this repository. The fix is a check that rules out the whole category.

The source is docs/mistakes-to-rules.md. The build reads its tables each time it runs. Nothing on this page is copied by hand.

A test fails when a row names a file, a guard check, a zanity rule or a test title that does not exist. The test is scripts/audit/mistakes-table.test.ts.

Mistakes caught by a rule

The file holds {{mistakesCaught}} rows. Each row has a mistake, a category, the rule that catches it and the test that proves the rule can fail.

A check number in the Rule column links to the CI checks page. A sub-check such as 10a links to its parent check.

Mistakes with no deterministic rule yet

These mistakes still depend on review. The file holds {{mistakesOpen}} of them. Each row says why no check catches it.

A row in the second table is a known gap. It is not a hidden one.
